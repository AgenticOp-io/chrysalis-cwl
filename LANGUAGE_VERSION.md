# CWL language version

| Field | Value |
| --- | --- |
| **Language** | Chrysalis Web Language (CWL) |
| **Goal** | DNA of web languages. A language in its own right. Able to replace any web page. Tip `1.0.75` emits a static Hosting site from the genome (golds `68`–`83`). The host fills year and device tokens and refuses live `agenticops` deploy from the demo path. WebSocket duplex, raw SQL text, and unclassified client script stay holes. |
| **Version** | `1.0.75` |
| **Status** | Host site emit |
| **Date** | 2026-10-05 |

## What this version means

- **Host site emit:** `npm run emit:site` writes static HTML from a `.cwl` module. The host pass fills `year host` and `device host` from declared classes and `below`. CSS and image bytes stay host files (`--assets`). `npm run deploy:demo` publishes only `agenticop-cwl-demo` and refuses live `agenticops` / `agenticop-io`
- **Gold `83`:** three pages emit with year and device filled. The AgenticOps genome emits 26 pages the same way. No Cloud Function
- Prior tip **1.0.74:** database engines and bound row operations (gold `82`)
