# 71 — host year

`year host;` means the calendar year is the host's. `<!-- cwl:year -->` stays in the document. CWL does not read the clock and does not write digits.

`/bare` declares `year host` with no token, so the reason is `cwl:missing-year-slot`.

The menu toggle and the mobile/desktop switch stay `unsupported:opaque-script`. CSS, images, and hosting stay outside the language.
