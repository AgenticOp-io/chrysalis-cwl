# AgenticOps site asset bytes (CWL SoR)

These files are the owned bytes for `site.cwl` URLs (`/agenticops.css`, `/logo.svg`, explainer PNGs).  
`npm run emit:site` copies them next to emitted HTML. CWL does not parse CSS or invent pixels.

Brand `agenticops-web` may mirror them for Hosting ops. The genome tree is the source of record.
