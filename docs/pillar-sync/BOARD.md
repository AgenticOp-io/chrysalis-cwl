## Honesty

No SQL invent. Cookie values never enter CWL. A cookie is session, csrf, or an enumerated preference. A redirect is a same-site path; off-site targets are `unsupported:open-redirect`. A page body may be a multi-line HTML document. `<!-- cwl:body -->` is the one shell slot. CSS, browser script, images, and hosting stay outside the language. WebSocket stays a hole. No SMTP / CORS / CDN / HTTP-client invent.
