## Honesty

No SQL invent. Cookie values never enter CWL. A cookie is session, csrf, or an enumerated preference. A redirect is a same-site path; off-site targets are `unsupported:open-redirect`. A page body may be a multi-line HTML document. `<!-- cwl:head -->` is that page's title and meta. `<!-- cwl:page -->` is the page name. `<!-- cwl:active <page> <class> -->` marks the current page. The menu script, CSS, images, and hosting stay outside the language. WebSocket stays a hole. No SMTP / CORS / CDN / HTTP-client invent.
